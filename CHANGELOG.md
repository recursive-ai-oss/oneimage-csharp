# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - unreleased

First release.

- Lazy, tiled, streaming `Image` and mutable `Canvas` on one engine.
- Codecs: PNG (including APNG), JPEG, WebP, GIF, TIFF (including BigTIFF), BMP and ICO.
- ICC color management, resampling, geometry, tone and filter operations, and compositing.
- Depends only on the .NET base class library; NativeAOT- and trim-compatible.
